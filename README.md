# rashi-bhansali-tax-docs-config
GitOps config repo for taxdocs-api — Kustomize overlays (dev/staging/prod) and Argo CD AppProject/Application/ApplicationSet definitions, synced by Argo CD running in the taxdocs-dev cluster.

**Week 6, Day 3:** Added the AWS infrastructure substrate as four raw CloudFormation stacks under `cfn/`: retained bootstrap and artifact S3 storage, a GitHub OIDC CloudFormation deployment role, a three-AZ VPC with environment-conditioned NAT gateways, and an RDS PostgreSQL application stack that imports network exports and resolves its password from Secrets Manager. Every stack was exercised locally through reviewed CREATE/UPDATE ChangeSets against Floci, while `.github/workflows/cfn-validate.yml` gates CloudFormation PRs with `cfn-lint`, strict `cfn-nag`, and a Floci-backed `validate-template` compatibility check. `taxdocs-api/INFRA.md` documents deployment order, exports/imports, retention, the reference-shape audit, and the AWS-only behavior that Floci could not prove, including OIDC federation, drift detection, export-in-use deletion protection, and replacement semantics.
